# 차입금 원리금 관리 — 프론트엔드 (v1.1: 업무 화면 전체)

React 18 + TypeScript + Vite + Tailwind CSS 4. 백엔드 API(`/api/v1`)를 프록시로 호출합니다.

## 실행
```bash
npm install
npm run dev            # http://localhost:5173  (백엔드는 127.0.0.1:8000)
# 백엔드 주소가 다르면
BACKEND_URL=http://127.0.0.1:8001 npm run dev
npm run build          # 타입검사 + dist/ 생성
npm run preview        # 빌드 결과 확인 (http://localhost:4173)
```
화면을 빠르게 보려면 백엔드 README의 '데모 데이터'로 데모 DB를 만들고 로그인하세요(비밀번호 모두 `demo1234!`):
관리자 `demo-admin@`, 자금담당 `demo-fund@`, 결재권자 `demo-approver@`, SPC 담당자 `demo-spc@`, 조회자 `demo-viewer@` (`example.com`).
상단 '기준일'을 2026-10-28로 두면 모든 알림 패널이 채워진 상태를 볼 수 있습니다.

## 화면 구성 (대시보드)
- **주요 지표**: 기숙사 수, 총 차입금, 총 잔여원금(계획 기준), 금월·익월·금년 상환예정, 금년 이자예정, 금리변동 예정, 미납, (기간 지정 시) 기간 상환예정
- **업무알림**: 상환 예정(D-15/7/3/1, 휴일이면 납부기한 표시), 금리변동 예정(영업일 D-30), 미납·일부납부, 확인 필요(계산오류·잔액불일치·금리 미등록·공휴일 미등록)
- **월별 상환예정** 막대차트(원금/이자, 마우스 올리면 금액, '표로 보기' 지원), **재원별 잔여원금**
- **Excel 자료 8종**(대시보드 맨 아래): 전체/기숙사별/기금별 원리금 테이블, 기간 상환내역, 실제 상환이력, 중도변수 이력,
  금리변동 이력, 기숙사별 안내문 데이터. 기숙사·재원·기간은 위 검색조건을 그대로 쓴다.
- **차입금 현황 표**: 검색·정렬·20건씩 페이지·CSV 내려받기(엑셀에서 한글 깨짐 없음)
- 검색조건: 기숙사·재원·상태·기간 + 상세 조건(학교·SPC·담당자·금리유형·상환유형·상환주기·금리변동 여부·중도변수 여부)
- 라이트/다크 화면 전환, 휴대폰 폭 대응. 사이드바의 나머지 메뉴는 다음 단계에서 화면을 붙입니다('예정' 표시).

### 증빙자료·상환일 메모 (Phase 17)
- **증빙자료**: 차입금 상세 › 증빙자료 탭(이 차입금의 모든 첨부를 대상별로), 이벤트 등록 직후 바로 첨부, 이벤트 이력·결재함의 `증빙`, 납부 내역의 `입금증`.
  올리기 전에 형식·용량을 화면에서 먼저 확인하고, 서버가 다시 검사합니다. 지우지 않고 사용중지(사유 필수)만 합니다.
- **상환일 메모**: 원리금 테이블 비고 열의 `+ 메모` → 메모 남기기·이력 보기. 버전이 바뀌어도 상환일 기준으로 계속 보이고 Excel 비고에 함께 나갑니다. 조회자는 읽기만.

주소는 `#/loans`, `#/loans/<id>?tab=schedule`, `#/events?tab=list`, `#/payments?tab=loan&loan=<id>` 처럼 화면마다 있어 새로고침·즐겨찾기가 됩니다.

## 로그인 알림 팝업 · 계정
- 로그인하면 처리할 일이 있을 때 팝업이 뜬다.
  - **중도변수 미처리**(재단 자금담당·결재권자·관리자): 금리변동 미등록/미반영, 조기상환 미등록 의심, 납부 회차 연결 필요, 결재 대기
  - **관리자 안내**(시스템관리자): 공휴일 연동 미설정·공휴일 미등록·동기화 실패, 백업 미실행·실패
  - '확인했습니다' → 중도변수는 오늘 하루, 관리자 안내는 7일간 숨김(그때까지 미해결이면 다시). '나중에' → 이번 접속 동안만 닫음.
- 상단 사용자 이름을 누르면 **비밀번호 변경**(규칙 안내 포함). 바꾸면 모든 로그인이 끊기고 다시 로그인한다.
- 로그인 5회 연속 실패 시 15분 잠금 — 화면에 남은 시도 횟수·잠금 안내가 나온다.
- 조회자 중 다운로드가 제한된 계정은 CSV 다운로드 버튼이 보이지 않는다(서버도 막음).

## 점검
```bash
npm run typecheck
# 데모 DB 백엔드 + npm run build && npm run preview 상태에서
pip install playwright && python e2e/smoke.py http://127.0.0.1:4173
python e2e/loans.py http://127.0.0.1:4173     # 차입금·원리금 테이블 화면(검증용 차입금을 새로 만든다)
python e2e/work.py http://127.0.0.1:4173      # 이벤트·납부·공문·알림·관리자 화면(데이터를 바꾸므로 새로 만든 데모 DB에서)
python e2e/attach.py http://127.0.0.1:4173    # 증빙자료·상환일 메모(새로 만든 데모 DB에서)
```
로그인 실패 안내, 알림 팝업(나중에·재표시), KPI·알림 값, 검색조건 연동, 표 검색·정렬, 다크모드, SPC 권한 범위,
조회자 다운로드 제한, 비밀번호 변경(변경 후 재로그인·원복), 360/390/768px 가로 넘침 없음을 확인합니다. 여러 번 돌려도 데모 데이터가 바뀌지 않습니다.

## 보안
로그인 토큰은 브라우저 탭을 닫으면 사라지는 sessionStorage에 둡니다. 계좌번호 등 실제 정보는 코드에 넣지 않습니다(데모는 가상 값).
